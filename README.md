# Harvard AI Demos

Interactive browser adaptations of projects completed during [Harvard CS50's Introduction to Artificial Intelligence with Python](https://cs50.harvard.edu/ai/).

**[Open the live collection](https://raulesteveza.github.io/demos/Harvard_AI/)**

- 🇬🇧 [English full documentation](README_en.md)
- 🇪🇸 [Documentación completa en español](README_es.md)

## What is this repository?

This repository turns twelve course projects into small, bilingual visual experiences. The demos make each algorithm's decisions easier to inspect and run entirely in the browser, without a backend or external dependencies.

> [!IMPORTANT]
> These are educational reinterpretations, not complete replicas of the original assignments. Some use reduced datasets, vocabularies or models to remain fast and self-contained. The [original Python projects](https://github.com/RaulEstevezA/harvard_ai) retain the full course scope.
